# Online Event Ticket Booking System

## Features

* User Authentication with JWT
* Event Management
* Seat Selection
* Seat Locking
* Booking Management
* Razorpay Payment Integration
* My Bookings Dashboard
* Spring Boot REST APIs
* React Frontend

## Tech Stack

Frontend:

* React
* Vite
* CSS

Backend:

* Spring Boot
* Spring Security
* JWT
* Hibernate

Database:

* MySQL

Payment:

* Razorpay
* UPI / Card / Net Banking

## Run Backend

mvn spring-boot:run

## Run Frontend

npm install
npm run dev
