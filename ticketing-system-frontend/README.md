# Online Event Ticket Booking System

## Features

* User Authentication with JWT
* Event Management
* Seat Selection
* Seat Locking
* Booking Management
* Razorpay Payment Integration
* My Bookings Dashboard
* Spring Boot REST APIs
* React Frontend

## Tech Stack

Frontend:

* React.js
* Vite
* CSS
* React Router
* JavaScript

Backend:

* Spring Boot
* Spring Security
* JWT
* Hibernate
* Spring Data JPA
* WebSocket

Database:

* MySQL

Payment:

* Razorpay
* UPI / Card / Net Banking
  
Other Tools:

* Redis (Seat Locking)
* Maven
* Git & GitHub
* Postman

## Run Backend

mvn spring-boot:run

## Run Frontend

npm install
npm run dev
